# The approach runs

Part of [Terrain Precision Fix Diag 1](../README.md): the save and the logs of the readings taken
with [the approach protocol](../docs/the-protocol-approach.md). What those readings say is in
[The measurements: coming back to a craft you left](../docs/the-measurements-approach.md).

- [`approach-kerbin.sfs`](approach-kerbin.sfs) — the save the protocol uses: a craft parked on the
  flat grass west of the KSC, and a rover beside it. Copy it into the folder of a sandbox game and
  load it from that game.
- [`runs/approach-stock-6cycles.log`](runs/approach-stock-6cycles.log) — the `KSP.log` of the session
  the six round trips were taken in.
- [`runs/approach-diag1-stock.log`](runs/approach-diag1-stock.log) — the `KSP.log` of an earlier
  session, kept for the record: its round trips stayed within range of the parked craft, so the game
  never unloaded it and there was nothing to read.
